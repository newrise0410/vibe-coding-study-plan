# Day 0 — 준비 (시작 3일 전)

이번 스터디는 외부 서비스를 5개 쓴다. **계정 만들기에서 첫날을 날리지 않는 것**이 목표다.

가입만 미리 해두고, 각 서비스가 무슨 역할인지 한 줄씩만 알아둔다. 설정은 해당 Day에 한다.

⏱ 50~60분

---

## 1. 원리 먼저 — 왜 서비스가 이렇게 많나

옛날에는 서버 한 대에 전부 넣었다. 화면도, 데이터도, 이미지도, 로그인도.
지금은 **잘하는 곳에 각각 맡긴다.** 이유는 하나다 — **각각 특성이 완전히 다르기 때문**이다.

| 맡기는 것 | 어디에 | 왜 나눴나 |
|---|---|---|
| 화면 + 서버 코드 | **Vercel** | 코드는 자주 바뀌고, 배포는 순간이어야 한다 |
| 데이터 (상품·주문·회원) | **MongoDB Atlas** | 절대 사라지면 안 되고, 빠르게 찾을 수 있어야 한다 |
| 이미지 파일 | **Cloudinary** | 크고, 안 바뀌고, 전 세계에서 빨리 받아야 한다 |
| 로그인 | **Google (OAuth)** | 남의 비밀번호를 내가 보관하는 건 위험하다 |
| 결제 | **포트원 + KG이니시스** | 카드 번호를 내가 만지면 안 된다. 법적으로도, 실무적으로도 |

마지막 두 줄이 중요하다.
**비밀번호와 카드번호는 되도록 내가 안 만지는 게 정답이다.** 보관하는 순간 지킬 책임이 생긴다.
"남에게 맡긴다"는 게 게으른 선택이 아니라 **표준적인 설계**다.

이 그림이 오늘 만들 계정들의 정체다.

## 2. 하는 일 — 계정 만들기

**순서대로** 한다. 뒤로 갈수록 앞의 계정이 필요하다.

### ① Cursor 설치 — https://cursor.com

- "VS Code 설정 가져오기"는 Skip
- 단축키는 기본값 그대로

### ② GitHub — https://github.com/signup

- 코드 원본 보관소
- 아이디는 나중에 주소에 쓰일 수 있으니 부끄럽지 않은 걸로

### ③ Vercel — https://vercel.com

- **반드시 "Continue with GitHub"로 가입한다.** 이메일로 따로 가입하면 배포 연동이 꼬인다
- 여기서 제일 많이 실수한다

### ④ MongoDB Atlas — https://www.mongodb.com/cloud/atlas/register

- 가입 → `Create` → **M0 (Free)** 선택 → 지역은 `Seoul` 또는 가까운 곳
- 클러스터 이름은 기본값
- **Database Access**에서 사용자 하나 만들기 → **아이디와 비밀번호를 메모장에 적어둔다** (다시 못 본다)
- **Network Access**에서 `Add IP Address` → **`0.0.0.0/0` (Allow from anywhere)**
  - 왜 이렇게 하는지는 Day 7에서 다룬다. 지금은 이대로 둔다

### ⑤ Cloudinary — https://cloudinary.com/users/register_free

- 가입 후 Dashboard에서 `Cloud name`, `API Key`, `API Secret` 위치만 확인해둔다
- **아직 아무 데도 복사해두지 않는다.** 키를 다루는 법은 Day 9에서 배운다

### ⑥ 포트원 — https://admin.portone.io

- 가입 → 상점 생성
- 결제 연동 → **테스트 채널 추가 → PG사 `KG이니시스` 선택**
- 여기까지만. 설정은 Day 12에 한다

> 사업자등록증이 없어도 **테스트 채널은 만들 수 있다.** 실거래만 계약이 필요하다.
> 만약 테스트 채널 생성에서 막히면 `#질문`에 올린다. 콘솔 화면이 종종 바뀐다.

### ⑦ 작업 폴더와 첫 파일

- 바탕화면에 `dulkkot-store` 폴더 생성 (**한글·공백 없이**)
- Cursor에서 `File > Open Folder`
- 우클릭 → `New File` → `index.html`, 내용은 한 줄만:
  ```html
  <h1>안녕 나는 여기 있다</h1>
  ```
- 저장 후 브라우저로 열어 확인

## 4. 부숴보기 🔨

| 실험 | 관찰 |
|---|---|
| A. `<h1>`을 `<p>`로 바꾼다 | 글씨 크기가 어떻게 되나? |
| B. 닫는 태그 `</h1>`을 지운다 | 화면이 어떻게 되나? |

## 막히면

| 증상 | 해결 |
|---|---|
| Windows "PC를 보호했습니다" | `추가 정보` → `실행` |
| Mac "확인되지 않은 개발자" | 시스템 설정 → 개인정보 보호 및 보안 → `확인 없이 열기` |
