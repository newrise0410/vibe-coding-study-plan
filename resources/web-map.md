# 한 장으로 보는 전체 동작 지도

15일 내내 여기로 돌아온다. 오늘 배운 게 전체 그림의 어디쯤인지 확인하는 용도다.

---

## 전체 흐름

```
[ 내 컴퓨터 ]
  app/  components/  lib/  .env.local
       │
       │  커밋 = 스냅샷  /  푸시 = GitHub로                      ← Day 3
       ▼
[ GitHub ]  원본 보관소 · 변경 이력
       │
       │  Vercel이 감지 → 자동 배포
       ▼
[ Vercel ]  Next.js 실행 (화면 + API)
       │
       │  ← 방문자가 주소 입력 → DNS → 요청 → 응답               ← Day 3, 6
       │
       ├─→ [ MongoDB Atlas ]  상품 · 주문 · 회원                 ← Day 7, 8, 11
       ├─→ [ Google OAuth ]   로그인                             ← Day 10
       ├─→ [ Cloudinary ]     이미지 (서명 발급만)               ← Day 9
       └─→ [ 포트원 ]         결제 조회·검증  ←웹훅──            ← Day 12, 13
       │
       ▼
[ 방문자의 브라우저 ]
   ① HTML 파싱 → DOM 트리                                        ← Day 2
   ② CSS 매칭 (캐스케이드) → 레이아웃 → 페인트                    ← Day 2, 3
   ③ JS 실행 → 이벤트 대기 → 상태 변경 → 다시 그림                ← Day 4, 5
```

---

## 가장 중요한 경계선

```
════════════ 브라우저 (남의 컴퓨터) ════════════
  · 코드가 다 보인다 (Ctrl+U, Sources 탭)
  · 사용자가 마음대로 고칠 수 있다
  · 여기서 온 값은 무엇이든 될 수 있다
  · 여기 있는 검증은 "친절"이지 "보안"이 아니다

──────────── 여기가 신뢰 경계 ────────────

════════════ 서버 (내가 통제하는 곳) ════════════
  · 비밀 키를 둘 수 있다
  · DB에 접속할 수 있다
  · 여기서 검사한 것만 믿을 수 있다
  · 금액·권한·결제 확인은 전부 여기서
```

**15일 중 절반의 개념이 이 선 하나에서 나온다.**

| 어디서 실행되나 | 확인하는 법 |
|---|---|
| `'use client'` 있음 | 브라우저. `console.log`가 브라우저 콘솔에 |
| `'use client'` 없음 | 서버. `console.log`가 터미널에 |
| `app/api/**/route.js` | 서버. 브라우저로 전송조차 안 됨 |
| `NEXT_PUBLIC_` 환경변수 | 브라우저로 전송됨 = 공개 |

## 신뢰의 사슬 — 3주차의 핵심

```
❌ 브라우저가 "이 상품 36000원이에요"         → 믿으면 안 됨
✅ 서버가 DB에서 가격을 조회해 계산            → 이게 진실

❌ 브라우저가 "결제 성공했어요"               → 믿으면 안 됨
✅ 서버가 포트원에 직접 조회해서 확인          → 이게 진실

❌ 화면에서 관리자 버튼을 숨김                → 보안 아님
✅ API 안에서 role을 검사                    → 이게 방어

❌ 폼에 min="0"을 걸어둠                     → 보안 아님
✅ 서버 검증 함수에서 범위를 검사              → 이게 방어
```

**패턴이 전부 같다.** "보여주는 곳"과 "판단하는 곳"을 분리하는 것.

## 개발자 도구 지도 (F12)

| 탭 | 보는 것 | 언제 |
|---|---|---|
| **Elements** | DOM 트리 + 걸린 CSS | 요소가 어느 코드인지, CSS가 안 먹힐 때 |
| **Console** | 에러 + 직접 명령 실행 | 뭔가 이상할 때 **가장 먼저** |
| **Network** | 요청·응답, 상태 코드, 용량 | API, 배포 문제, 느린 사이트 |
| **Application → Cookies** | 세션 쿠키 | 로그인 문제 |
| **Sources** | 브라우저에 전송된 코드 전부 | **비밀 키가 새는지 검사** (`Ctrl+Shift+F`) |
| **Lighthouse** | 성능·접근성·SEO 점수 | 마무리 점검 |

### 자주 쓰는 동작

| 하고 싶은 것 | 방법 |
|---|---|
| 이 화면 요소가 어느 코드인가 | 우클릭 → **검사** |
| 어떤 CSS가 이기고 지는가 | Elements → Styles → **취소선** |
| 캐시 무시하고 새로 받기 | **`Ctrl+Shift+R`** |
| API를 직접 호출해보기 | Console에서 `fetch(...)` |
| 비밀이 새는지 검사 | Sources → `Ctrl+Shift+F` → `secret`, `mongodb+srv` |
| 배포 환경 서버 로그 보기 | **Vercel → 프로젝트 → Logs** |

마지막 줄이 중요하다. **배포 환경에는 터미널이 없다.** 서버 에러는 Vercel 로그에서만 볼 수 있다.

## 문제 유형별로 어디를 보나

| 증상 | 먼저 볼 곳 | 흔한 원인 |
|---|---|---|
| 이미지가 안 보임 | Network → 404? | 경로, **대소문자** |
| CSS가 안 먹힘 | Elements → Styles 취소선 | 선택자 오타, 우선순위, 캐시 |
| 버튼이 안 눌림 | Console 빨간 에러 | `null` = 못 찾음, `<script>` 위치 |
| API가 405 | — | 함수 이름이 `GET`/`POST` 대문자인가 |
| API가 500 | **터미널 / Vercel Logs** | 서버 코드 에러. 브라우저엔 상세가 안 나온다 |
| DB 연결 실패 (배포만) | Atlas Network Access | `0.0.0.0/0` 없음 / Vercel 환경변수 누락 |
| 로그인이 풀림 | Application → Cookies | 쿠키 삭제됨 / `AUTH_URL` 불일치 |
| 결제 후 주문이 PENDING | Network → `/complete` | 서버 검증 호출 누락 |
| 웹훅이 안 옴 | 포트원 콘솔 발송 이력 | URL 미등록 / localhost 등록 |
| 로컬은 되는데 배포는 안 됨 | Vercel 환경변수 | **대소문자**, 환경변수 누락 |

## 알아두면 좋은 숫자

| | 기준 | 왜 |
|---|---|---|
| 페이지 전송량 | 1MB 이하 | 모바일 데이터 |
| LCP | 2.5초 이내 | 넘으면 이탈 |
| 색 대비 | 4.5:1 이상 | 밝은 데서 폰으로 읽기 |
| 본문 글자 | 16px 이상 | 모바일 가독성 |
| 반응형 분기 | 768px 근처 | 진짜 기준은 **내 레이아웃이 깨지는 지점** |

## 상태 코드

| 코드 | 뜻 | 누구 잘못 |
|---|---|---|
| `200` / `201` | 정상 / 생성됨 | — |
| `304` | 안 바뀜, 캐시 쓰세요 | — |
| `400` | 요청이 잘못됨 | 보낸 쪽 |
| `401` | 로그인 안 됨 (**인증**) | 보낸 쪽 |
| `403` | 권한 없음 (**인가**) | 보낸 쪽 |
| `404` | 그런 거 없음 | 보낸 쪽 |
| `405` | 그 방식은 안 받음 | 보낸 쪽 |
| `500` | 서버가 터짐 | **나** |

**400번대는 보낸 쪽, 500번대는 나.** 이 구분만으로 디버깅 방향이 반으로 준다.

## 용어 최소 사전

| 용어 | 한 줄 |
|---|---|
| **DOM** | 브라우저가 HTML을 읽어 만든 트리. JS가 만지는 대상 |
| **캐스케이드** | CSS 규칙이 겹칠 때 이기는 순서 |
| **컴포넌트 / props** | 재사용하는 화면 조각 / 밖에서 넣어주는 값 |
| **서버 컴포넌트** | 서버에서 실행되는 컴포넌트. DB·비밀키 사용 가능 |
| **API 라우트** | 브라우저가 부를 수 있는 서버 함수 |
| **컬렉션 / 문서** | MongoDB의 표 / 행 |
| **환경변수** | 코드 밖에 두는 설정값. 비밀을 여기 둔다 |
| **세션 / 쿠키** | 서버가 나를 기억하는 방법 / 브라우저가 자동으로 붙여 보내는 메모지 |
| **인증 / 인가** | 너 누구야(401) / 너 이거 해도 돼(403) |
| **OAuth** | 비밀번호를 안 받고 구글에게 신원을 물어보는 방식 |
| **서명(signature)** | 서버가 발급한 일회용 허가증 |
| **웹훅** | 남의 서버가 우리 서버로 보내는 알림. 방향이 반대 |
| **멱등성** | 같은 요청이 두 번 와도 결과가 같은 성질 |
| **PG사** | 카드사와 우리 사이를 중계하는 결제대행사 (KG이니시스) |
